# 📂 PyFile Organizer 🐍

[![Python Version](https://img.shields.io/badge/python-3.7+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A smart, automated Python script that tidies up your messy folders! It instantly categorizes files into clean subdirectories based on their file extensions.

---

## ✨ Features

* 🚀 **Fast Execution:** Organizes hundreds of files in seconds.
* 📂 **Smart Categorization:** Automatically creates folders for:
    * `📸 Images` (JPG, PNG, SVG...)
    * `📄 Documents` (PDF, DOCX, TXT...)
    * `💻 Scripts` (PY, JS, HTML...)
    * `🎥 Media` (MP4, MP3, MKV...)
* 🛠️ **Zero Dependencies:** Uses only standard Python libraries.
* 🧹 **Prevents Clutter:** Keeps your `Downloads` or `Desktop` looking professional.
